# shared/fixtures/

Casos de prueba en JSON que se ejecutan **en Python (pytest) y en TypeScript (Vitest)**, para garantizar que ambos lenguajes calculen igual los precios del carrito.

Ejemplo de caso:

```json
{
  "descripcion": "Plato armado completo",
  "pasta": "fettuccine-tinta-calamar",
  "salsa": "bolonesa",
  "proteina": "albondigas-carne",
  "total_esperado": 32500
}
```
